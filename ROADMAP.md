# Roadmap
Updated: 2026-11-26

This repo holds the `j-skills` skills and runs jflow in GitHub mode
(`git config jflow.mode github`), so its roadmap is the repo's open
[GitHub issues](https://github.com/johnviklund/j-skills/issues): the `next` label marks Next up, and
`roadmap` and `roadmap tidy` read them. Undecided intake lives in [TODO.md](TODO.md), what shipped
lives in [WORKLOG.md](WORKLOG.md) and git, and done items and earlier goals sit in
[ROADMAP_ARCHIVE.md](ROADMAP_ARCHIVE.md). Budgets count sessions or changed lines.
